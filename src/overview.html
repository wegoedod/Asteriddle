별잇기(Byeolitgi) API 매뉴얼. 별의 배치만 보고 별자리를 유추해 선으로 잇는 학습형 별자리 게임이다.

계층 구조

  • UI {@link byeolitgi.ui}: 화면 표시와 사용자 입력. {@link byeolitgi.ui.MainFrame} 이 화면 전환·게임 시작·자동 저장을 맡는다.
  • 게임 로직 {@link byeolitgi.game}: 기본 문제 모드와 밤하늘 모드의 진행, 연결선 편집, 정답 판정, 힌트·정답 보기.
  • 규칙·계산 {@link byeolitgi.policy}, {@link byeolitgi.astro}: 난이도·점수·관측 기준 값과 천문 계산.
  • 데이터 {@link byeolitgi.model}, {@link byeolitgi.data}, {@link byeolitgi.save}: 별·별자리 엔티티, 데이터 파일 읽기, 진행 상황 저장.

실행

java -jar ssd_ip_cp4_2026f_233575_app.jar
JDK 17 이상이 필요하다. 진행 상황은 ~/.byeolitgi/save.properties 에 자동 저장된다.
